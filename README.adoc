= Svgpng

Svgpng is a byte-oriented Ruby API for rendering SVG to PNG. Its public contract
is being defined before the native renderer is implemented. The current checkout
contains a Ruby API shell and native pixel/encoder components; native rendering, package artifacts, and
cross-platform byte-identity gates are pending. No native output or platform
support is claimed yet.

== Current status

The intended Ruby boundary and fixed rendering contract are recorded in
link:docs/decisions/svg-to-png.md[the rendering decision]. Rendering currently
raises `Svgpng::UnsupportedPlatformError` because no native renderer is shipped.
Installing and requiring the Ruby shell is intended to work on any Ruby platform
without probing system libraries.

== Intended interface

`Svgpng.render(svg_bytes, profile: {}, fonts: {}, fallback_fonts: [])` accepts
SVG bytes and caller-supplied fonts. It returns a `Svgpng::Result` with
`png_bytes`, `width`, `height`, `warnings`, and `font_manifest`. The API accepts
no filesystem, network, base-directory, resource-map, or loader input. Font
faces use `Svgpng::FontFace.new(bytes:, source_id:)`; metadata is read from the
font bytes rather than caller declarations.

The fixed limits and PNG encoding choices are design requirements, not evidence
that native enforcement has been delivered. The decision document records the
validation algorithm, errors, owned native components, target packages, and the
checks still required before support can be advertised.

== Developer checks

Run `bundle exec rspec` and `bundle exec rubocop`. The default suite includes
the dependency-free C pixel conversion checks and native loader controls.
The loader binds pixel conversion and PNG encoding primitives; it is not a rendering backend.
Requiring the shell does not load that binding.

The PNG encoder source requires libpng 1.6.59 and zlib 1.3.2. To run its
round-trip, chunk-profile, deterministic-byte, and allocation-failure assertions,
provide verified static dependency installations:

[source,sh]
----
SVGPNG_LIBPNG_PREFIX=/path/to/libpng-1.6.59 \
SVGPNG_ZLIB_PREFIX=/path/to/zlib-1.3.2 \
bundle exec rake native:check_encoder
----

This developer task invokes a C11 compiler (`SVGPNG_CC`, or Ruby's configured
compiler) and links the explicit `lib/libpng16.a` and `lib/libz.a` archives.
Missing dependencies and different header/runtime versions fail the check.
It does not establish source provenance, a complete renderer dependency closure,
cross-platform output identity, or an installable native renderer package.
